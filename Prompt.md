The search in this project hands off to AI if an API Key is set up in bahai-research.properties. The hand off is supposed to come up with search words out of a potential sentence of input. At the end of the search, a second handoff to AI is supposed to help with selecting the most prominent quotes to satisfy the query request. After using for some time, I find that the actual working of the quote search words is not as effective as I would like. Please give me an evaluation of this process and give me your thoughts of how it might be improved. Keep in mind that there is a common search project ../BahaiSearchCommon that is shared between this Windows/Linux front end and ../BahaiResearchA, an Android project. The Android project does not use AI because it's limitations on adding an API key without security risk. The Search is meant to work without AI and actually functions quite well. So well that I am wondering if the AI is really necessary. After using a while I got better at selecting 3 key words that allows me with high confidence to select a direct quote that comes to the top by  using NEAR* and the rating system. It also allows me to find key words in an entire paragraph that could match across several topic areas with AND search. It ends to OR search that will get a great variety of quotes that might trigger a better follow on search. The main search routines are in ../BahaiSearch/Common.
